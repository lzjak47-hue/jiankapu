# 08 · 前端：前台商城 site

> 源码目录 [apps/web-react/src/site/](../../apps/web-react/src/site/)，入口 `index.html → src/site/main.tsx`。

## 1. 装配与路由

- [main.tsx](../../apps/web-react/src/site/main.tsx)：挂载根，`StrictMode`，引入 tokens/base/site.css。
- [App.tsx](../../apps/web-react/src/site/App.tsx)（`SiteApp`）：Provider 嵌套
  `ToastProvider → SiteProvider → BootGate → BrowserRouter`。

路由（均在 `SiteLayout` 下）：

| 路径 | 组件 |
| --- | --- |
| `/` | `HomePage` |
| `/product/:id` | `ProductPage` |
| `/query` | `QueryPage` |
| `*` | 重定向 `/` |

## 2. 全局状态：SiteContext + BootGate

- [SiteContext.tsx](../../apps/web-react/src/site/SiteContext.tsx)：`SiteProvider` + `useSite()`；
  用 `useAsync` 拉 `/api/public/bootstrap`，暴露 `settings / categories / products / announcements / endpoints /
  loading / error / reload / refreshProducts / findProduct / categoryName`。
- [BootGate.tsx](../../apps/web-react/src/site/BootGate.tsx)：加载中显示骨架屏，出错显示可重试错误页。

## 3. 布局 layout/

| 文件 | 组件 | 说明 |
| --- | --- | --- |
| `SiteLayout.tsx` | `SiteLayout` + 内部 `FloatingButtons` | 页头 + 内容区 + 页脚；悬浮「客服/回顶部」按钮（客服填网址是外链、填 QQ 号转可复制账号） |
| `AnnouncementBar.tsx` | `AnnouncementBar` | 多公告轮播 |
| `Header.tsx` | `Header` | Logo、导航、搜索框、移动端菜单 |
| `Footer.tsx` | `Footer` | 版权 / ICP / 后台入口 / 分类链接（带锚点定位分类） |

## 4. 页面 pages/

- [HomePage.tsx](../../apps/web-react/src/site/pages/HomePage.tsx)：Hero + 商品网格
  （分类筛选 / 关键词 / 排序，支持 `?q=&category=` 地址直达）+ 购买流程 + 优势 + FAQ 手风琴；管理 `BuyModal` 开关。
- [ProductPage.tsx](../../apps/web-react/src/site/pages/ProductPage.tsx)：规格选择（按 `specStock` 禁用售罄）、
  数量选择、详情/须知/教程三 Tab。
- [QueryPage.tsx](../../apps/web-react/src/site/pages/QueryPage.tsx)：`QueryPage` + `OrderCard`；
  订单号或联系方式查单，`?no=` 自动查询；结果含卡密与订单状态）。

## 5. 组件 components/

- [ProductCard.tsx](../../apps/web-react/src/site/components/ProductCard.tsx)：商品卡（价格、销量、库存、售罄态）。
- [BuyModal.tsx](../../apps/web-react/src/site/components/BuyModal.tsx)：**完整支付状态机**，`BuyModal` + `Stepper` 四步：

```
step 0 确认订单（规格/数量/联系方式）→ POST /orders 创建订单
step 1 选择支付渠道（未配置渠道标「暂不可用」且默认不选中）
step 2 扫码支付：二维码以 data URL 交给 <img>（不是 dangerouslySetInnerHTML，排除 SVG 内联脚本）
      ├─ 测试渠道：「模拟支付成功」按钮调 POST /orders/:no/pay
      └─ 真实渠道：useCountdown 倒计时(与后端关单时间同步) + useInterval(3s) 轮询 GET /orders/:no
step 3 获取卡密：SecretList 展示 + 一键复制；支付成功 refreshProducts() 刷新库存
```

- 联系方式为空/全空白时前端先拦截（后端仍兜底）。
- 轮询到 `已发货` 即展示卡密；`已关闭` 提示超时并可重下单。
