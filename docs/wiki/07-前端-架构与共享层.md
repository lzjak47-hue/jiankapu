# 07 · 前端：架构与共享层

> 源码目录 [apps/web-react/](../../apps/web-react/)。React 19 + TypeScript strict + Vite 7，
> **一个工程构建两个 SPA**：前台商城（:2001）与管理后台（:2002）。

## 1. 构建配置

- [vite.config.ts](../../apps/web-react/vite.config.ts)：
  - `build.rollupOptions.input` 双入口：`site: index.html`、`admin: admin/index.html`，一次构建产出
    `dist/index.html` 与 `dist/admin/index.html`，共享 React/Router 抽公共 chunk。
  - 别名 `@ → src`；`server.proxy` 把 `/api` 代理到 `VITE_API_TARGET || http://localhost:2002`（dev:web 用）。
- [tsconfig.json](../../apps/web-react/tsconfig.json)：`strict: true`、`noUnusedLocals/Parameters`、
  `noFallthroughCasesInSwitch`、`verbatimModuleSyntax`、`moduleResolution: bundler`、`jsx: react-jsx`、`noEmit`。
- 构建脚本实际是 `tsc --noEmit && vite build`（类型检查零错误才出产物）。
- [vitest.config.ts](../../apps/web-react/vitest.config.ts)：继承 vite 配置；`jsdom` 环境、globals、
  `setupFiles: src/test/setup.ts`、匹配 `src/**/*.test.{ts,tsx}`。
- 后台入口 [admin/index.html](../../apps/web-react/admin/index.html) 加 `<meta name="robots" content="noindex,nofollow">`。
- 运行时配置：服务端注入 `window.JKP_RUNTIME`（`types.ts` 中声明 `Window['JKP_RUNTIME']`），前端据此拼跨端口地址。

## 2. shared/types.ts — 接口契约唯一事实来源（518 行）

所有响应/请求类型与后端一一对应。核心类型族：

| 类型族 | 成员（示例） |
| --- | --- |
| 响应壳 | `ApiOk<T>` `ApiFail` `ApiResponse<T>`（`Paged<T>` 分页） |
| 站点/设置 | `PublicSettings` `PublicPaymentSettings`(channels/channelReady) `BootstrapData` `Announcement` `AdminSettings` `SettingsInput` `ChannelStatus` |
| 商品 | `Category` `Product` `ProductInput` |
| 订单 | `OrderStatus` `OrderPayment` `PublicOrder` `AdminOrder` `CreateOrderInput` `OrderStats` |
| 卡密 | `CardStatus` `Card` `CardStats` `ImportCardsResult` |
| 客户 | `ShopUser` `CustomerOrder` `CustomerDetail` `UserStats` |
| 提醒/日志 | `AlertEvent` `AlertsFeed` `LogEntry` |
| 概览 | `DashboardStat` `SeriesPoint` `TopProduct` `RecentOrder` `SystemInfo` `DashboardData` |
| 认证 | `AdminInfo` `Captcha` `RuntimeConfig` |

> 约定：只读类型与提交类型分开（如 `SettingsInput` 不含 `id`），编译器挡掉字段错配。
> 运行时**不做 schema 校验**——它保证「字段名一致」而非「数据可信」（可加 zod，README 有说明）。

## 3. shared/api.ts — 唯一网络出口（298 行）

- `class ApiError extends Error`：带 `status / code / details`。
- `request<T>(method, url, body, opts)`：解析 `{ok,data}`；非 JSON / `ok:false` 抛 `ApiError`；
  **401 且非 `silent401` 调全局未授权处理器**（admin 注册为跳登录页）；内部 `qs()` 忽略空参数。
- `setUnauthorizedHandler(fn)`：会话过期统一跳转。
- 导出的默认 `api` 对象：
  - `api.public`：`bootstrap` `stats` `product` `createOrder` `getOrder` `payOrder` `cancelOrder` `queryOrders`
  - `api.admin`：认证（`captcha login logout me changePassword`）、`dashboard`、
    商品（`products product createProduct updateProduct toggleProduct deleteProduct batchProducts`）、
    分类 CRUD、订单（`orders orderStats order resendOrder closeOrder refundOrder`）、
    卡密（`cards cardStats cardsExportUrl importCards deleteCard batchDeleteCards`）、
    客户（`users userStats userDetail`）、`alerts`、设置（`settings saveSettings testNotify`）、`logs`

## 4. shared/hooks.ts — 通用 hooks

| hook | 签名 | 说明 |
| --- | --- | --- |
| `useAsync` | `<T>(loader, deps) → {data, loading, error, reload, setData}` | 加载三态；`AbortController` 取消旧请求；卸载后不再 setState |
| `useDebouncedValue` | `<T>(value, delay)` | 输入防抖 |
| `useCountdown` | `(initial, onExpire)` | 支付倒计时 |
| `useInterval` | `(cb, delayMs \| null)` | 轮询（delayMs=null 即停） |
| `useRevealOnScroll` | `<T>()` | 滚动显现（`.reveal` 加 `is-in`） |
| `useLocalStorage` | `<T>(key, initial)` | 持久化状态 |

## 5. shared/components.tsx — 通用组件

`Modal`（Esc/遮罩关闭、锁滚动）、`Pagination`、`Switch`、`StatusTag`、`Empty`、`Skeleton`、
`TableSkeleton`、`TableEmpty`、`SecretList`（卡密列表 + 一键复制全部）、`StatCards`、`BlockHead`、
`SortSelect`、`SortableTh`（点表头循环 升序▲→降序▼→取消，带 `aria-sort`，配合 shared/sort.ts 的

## 6. ToastProvider / ConfirmProvider

- `ToastProvider` + `useToast() → {toast, success, warn, error}`，卸载清理定时器。
- `ConfirmProvider` + `useConfirm()`，Promise 风格确认框。
