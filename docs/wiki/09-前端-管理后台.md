# 09 · 前端：管理后台 admin

> 源码目录 [apps/web-react/src/admin/](../../apps/web-react/src/admin/)，入口 `admin/index.html → src/admin/main.tsx`。

## 1. 装配与路由

- [App.tsx](../../apps/web-react/src/admin/App.tsx)（`AdminApp`）：`ToastProvider → ConfirmProvider → BrowserRouter → AuthProvider`。

| 路径 | 组件 | 鉴权 |
| --- | --- | --- |
| `/login` | `LoginPage` | 公开 |
| `/` | `DashboardPage` | RequireAuth |
| `/products` `/products/new` `/products/:id` | `ProductsPage` / `ProductEditPage` | RequireAuth |
| `/categories` `/orders` `/cards` `/users` `/settings` `/logs` | 对应页面 | RequireAuth |
| `*` | 重定向 `/` | |

所有受保护页面套在 `RequireAuth → AdminLayout` 内。

## 2. AuthContext — 登录态管理

[AuthContext.tsx](../../apps/web-react/src/admin/AuthContext.tsx)：`AuthProvider` + `useAuth()`。

- 挂载即探测 `api.admin.me()`：有会话 → 进后台；无 → 跳 `/login`。
- 注册 `setUnauthorizedHandler`：任意请求 401（会话过期）→ 清状态跳登录页。
- 暴露 `admin / loading / refresh / setAdmin / logout`。
- ⚠️ 已知坑（有回归测试）：`me()` 刻意**不加 `silent401`**——曾经加了导致 401 不触发全局处理、
  壳层又不会跳转，打开后台一片空白。

## 3. AdminLayout + 顶栏组件

- [AdminLayout.tsx](../../apps/web-react/src/admin/layout/AdminLayout.tsx)：侧边栏分组导航（概览/商品/分类/订单/卡密/客户/设置/日志）
  + 顶栏（当前页标题、🔔 提醒铃铛、当前管理员头像菜单、前台入口）；移动端抽屉化；集成 `AlertsBell` 与 `ChangePasswordModal`。
- [AlertsBell.tsx](../../apps/web-react/src/admin/components/AlertsBell.tsx)：每 20s 轮询 `api.admin.alerts`；
  新订单 → 角标数字 + toast；库存预警 → 红点下拉；售罄 → 标红置顶跳卡密页。`since` 游标存 localStorage；
  打开面板时**冻结快照**并把位置记为已读（防止内容在眼前消失）。
- [ChangePasswordModal.tsx](../../apps/web-react/src/admin/components/ChangePasswordModal.tsx)：两次输入校验、原密码验证；
  修成成功后服务端踢掉其它会话 → 重新登录。

## 4. 页面 pages/（10 页）

| 页面 | 文件 | 功能要点 |
| --- | --- | --- |
| 登录 | `LoginPage.tsx` | SVG 验证码、账号密码；登录体带验证码 id；失败提示 |
| 概览 | `DashboardPage.tsx` | 指标卡（含同比）、近 7 天走势、热销 TOP5、最近订单、系统信息 |
| 商品 | `ProductsPage.tsx` | 三重筛选 + 点表头排序 + 分页；批量上架/下架/删除；库存预警标记 |
| 商品编辑 | `ProductEditPage.tsx` | 规格 chip 输入（`SpecChips`）、前台卡片实时预览、吸底保存；新增/编辑两用 |
| 分类 | `CategoriesPage.tsx` | 弹窗增改、启停；有商品禁删 |
| 订单 | `OrdersPage.tsx` | 多条件筛选 + 排序 + 下单 IP 展示；详情弹窗（IP/支付时间）；补发/关闭/退款；`?no=` 定位并**橙色高亮**该行（不弹详情） |
| 卡密 | `CardsPage.tsx` | 按商品+规格摊开库存；导入（必须选规格）/ 导出 CSV（带当前筛选）/ 批量删除（跳过已售，勾选框禁用）；点表头排序 |
| 客户 | `UsersPage.tsx` | `CustomerDetail` / `CustomerDetailModal`：购买记录卡 + 按 IP 下拉筛选（默认全部，选项带每 IP 订单数与最近时间）；点记录跳订单列表高亮 |
| 设置 | `SettingsPage.tsx` | 基础/交易/支付/公告/通知/SEO/安全七分区；支付区标「前台会显示哪几种、哪几种点不了」；密钥不回显（空=不改）；通知测试按钮透出真实错误 |
| 日志 | `LogsPage.tsx` | 谁、何时、做了什么、结果；keyword/result 筛选 |

## 5. 列表页共同模式

- 排序：点表头循环 升序▲ → 降序▼ → 取消（`SortableTh` + `sort.ts`），非法值被服务端安静回落。
- 批量：勾选后顶部出现操作条；「全选本页」只覆盖当前页；置为目标状态而非逐个切换。
- 空态/骨架：`TableEmpty` / `TableSkeleton`。
