# 04 · 后端：工具库 lib

> 源码目录 [src/lib/](../../apps/server/src/lib/)，均为无业务依赖的独立单元。
> 除 `pg` 外全部使用 Node 内置能力（`node:crypto` / `node:net` / `node:tls`）。

## 1. crypto.js — 口令散列与随机生成

| 导出 | 签名 | 说明 |
| --- | --- | --- |
| `hashPassword` | `(password) → Promise<string>` | scrypt + 16B 随机盐，格式 `scrypt$N$r$p$salt$hash` |
| `verifyPassword` | `(password, stored) → Promise<boolean>` | `timingSafeEqual` 比对防计时攻击 |
| `randomToken` | `(bytes=32)` | 会话令牌（hex） |
| `randomCaptchaCode` | `(length=4)` | 验证码，剔除易混字符 `0/O/1/I/L` |
| `randomCardSecret` | `(prefix, groups, size)` | 卡密生成 |
| `randomOrderNo` | `(prefix, date)` | 订单号 = 前缀 + 年月日 + 5 位随机 |
| `randomId` | `(bytes=12)` | 通用随机 id |

细节：scrypt 参数来自 config，`maxmem=64MB`；账号不存在时也执行一次假散列比对（auth.js 调用侧），消除响应时间差异。

## 2. qrcode.js — 二维码编码器（ISO/IEC 18004）

从零实现，字节模式、纠错等级 M、版本 1-10，超出容量抛 `RangeError`。

| 导出 | 签名 |
| --- | --- |
| `encode` | `(text, {ecLevel, mask}) → {version, size, modules, mask, ecLevel}` |
| `toSvg` / `toDataUrl` / `toText` | 编码结果的三种输出形态 |
| `rsGeneratorPoly` / `rsEncode` / `formatInfoBits` / `versionInfoBits` / `dataModuleCount` / `totalCodewordCount` | 测试用导出的底层部件 |

实现链路：GF(256) 伽罗华域（本原多项式 `0x11d`）→ Reed-Solomon 纠错 → 数据分块交织 →
定位/校正/定时图形落位 → 8 种掩码 + 四规则惩罚评分选优 → 格式/版本信息 BCH 编码 → SVG。

> 已通过 25 项规范一致性测试（Annex C/D 已知值比对、RS 伴随式全零验证等），但未用实体扫码器验证（见上线清单）。

## 3. wechatpay.js — 微信支付 APIv3 Native 扫码

| 导出 | 签名 | 说明 |
| --- | --- | --- |
| `nativeOrder` | `({...config, description, outTradeNo, amountYuan, notifyUrl, timeExpire}) → {codeUrl, raw}` | 下单 `/v3/pay/transactions/native` |
| `queryOrder` | `({...}) → {paid, closed, tradeState, paidAmount}` | 主动查单 |
| `decryptResource` | `(resource, apiV3Key) → object` | 回调报文解密 |
| `notifyOk` | `()` | 回调成功应答体 |

细节：
- 签名：`SHA256withRSA`，Authorization 头 `WECHATPAY2-SHA256-RSA2048`；
  待签串 = `方法\n路径\n时间戳\n随机串\nbody\n`。
- 金额单位为**分**（内部 `*100`）。
- 回调用 AES-256-GCM 解密：密钥 32 字节，密文末 16 字节为 authTag，可带 AAD；
  认证标签通过才证明报文来自持有 APIv3 密钥的一方。

## 4. alipay.js — 支付宝当面付

| 导出 | 签名 | 说明 |
| --- | --- | --- |
| `precreate` | `({...config, subject, outTradeNo, amountYuan, notifyUrl, timeoutExpress}) → {qrCode, raw}` | `alipay.trade.precreate` |
| `queryOrder` | `({...}) → {paid, closed, tradeStatus, paidAmount}` | 主动查单 |
| `verifyNotify` | `(params, alipayPublicKey) → boolean` | 回调验签 |

细节：
- RSA2 签名字符串：参数 key 升序 + 原始值 `k=v&…` 拼接，排除 `sign`；验签先剔除 `sign/sign_type`。
- 金额 `toFixed(2)` 字符串；时间戳东八区 `yyyy-MM-dd HH:mm:ss`。
- 响应节点名 = 方法名转下划线 + `_response`（如 `alipay_trade_precreate_response`），`code==="10000"` 才算成功。

## 5. mailer.js — 极简 SMTP 客户端（零依赖）

| 导出 | 签名 | 说明 |
| --- | --- | --- |
| `sendMail` | `({host, port, secure, user, pass, from, fromName, to, subject, text}) → {accepted, response}` | 完整 SMTP 会话 |

- 内部 `Session` 类按「三位数字+空格」判定多行响应结束。
- 465 端口隐式 SSL；587/25 自动 STARTTLS 升级；EHLO 失败降级 HELO。
- AUTH LOGIN 两步 base64 认证；正文 base64 + 点填充（行首 `.` 翻倍）；中文主题 RFC 2047 编码。
- 已通过 13 项对假服务器的协议级测试。

## 6. sms.js — 短信网关参数模板适配

| 导出 | 签名 | 说明 |
| --- | --- | --- |
| `sendSms` | `({url, method, bodyType, paramsTemplate, key, phone, content, successText}) → {accepted, response}` | 通用网关调用 |

- 参数模板支持 JSON 或 `k=v&…` 宽松格式；占位符 `{phone}` `{content}` `{key}` 替换。
- GET 拼查询串；POST 支持表单或 JSON 编码；`successText`（响应体包含即成功）判定成败；超时 10s。
- 不绑定任何厂商——「账号+密码+手机号+内容」型网关（互亿无线、短信宝等）直接套模板即可。

## 7. csv.js — CSV 导出（RFC 4180）

| 导出 | 签名 | 说明 |
| --- | --- | --- |
| `toCsv` | `(rows, columns) → string` | CRLF 换行，无 BOM（BOM 由路由层添加） |

- **公式注入防护**：以 `= + - @ \t \r` 开头的单元格加单引号前缀。
- 含逗号/引号/换行的字段双引号包裹，内部引号翻倍。

## 8. validate.js — 参数清洗（非法即抛 `ApiError(400)`）

导出：`str` `text` `int` `money` `oneOf` `bool01` `contact` `lines` `parseJsonArray` `toJsonArray` `orderBy`，常量 `ID_PATTERN`。

- 金额四舍五入两位小数；`contact` 刻意不校验格式（任意文本），仅限长 120。
- `orderBy` 排序白名单：未命中**安静回落默认**（不报错），并用 `hasOwnProperty` 防 `__proto__`/`constructor` 原型链注入。

## 9. errors.js — 统一错误层级

```js
class ApiError extends Error            // (status, code, message, details)
badRequest(400) / unauthorized(401) / forbidden(403) / notFound(404)
conflict(409) / tooMany(429) / upstream(502)
```

- 业务错误（如「库存不足」）→ 400/409；上游服务（微信、SMTP 网关）失败 → `upstream(502)` 且**透出真实原因**，
  管理员在后台测试通知时能看到「未配置 SMTP 服务器地址」而非笼统 500。

## 10. time.js — 本地时间字符串

导出：`nowStr` `strAfterMinutes` `isExpired` `secondsUntil` `parseStr` `todayStartStr` `recentDayLabels`。

统一 `"YYYY-MM-DD HH:mm:ss"` 定长字符串——字典序即时间序，可直接字符串比较；`logs.time` 即存此格式 TEXT。

## 11. logger.js — 日志

导出 `logger`（`info / warn / error / debug`）。带时间戳与 ANSI 颜色；`error` 打印堆栈；
`debug` 仅在 `process.env.DEBUG` 时输出。
